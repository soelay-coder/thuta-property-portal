# Property Portal

Property Portal is a marketplace for finding and sharing homes and other properties in Yangon, Mandalay, and Bago. Visitors can search public listings, view property details, and contact listers. Account holders can post and manage listings, which are reviewed before appearing publicly.

Property Portal is available through a web app, with a companion mobile app in development. The API supports both clients.

See [SPEC.md](SPEC.md) for product features and [AGENTS.md](AGENTS.md) for stable project boundaries and technical decisions. For project-specific setup, see the [web app](app/README.md), [API](api/README.md), or [mobile app](mobile/README.md) README.
